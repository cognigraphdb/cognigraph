# Semantic Neurons fixtures

Corpora, kits and dated measurements support the
[engineering research records](../../docs/research/README.md). Each experiment
folder owns its protocol and results; evaluation kits follow `blind/TEMPLATE`.

## Public distribution

The public snapshot excludes the restricted corporate vendor-research and
market-research kits, together with their stored judge replays. Original files
and hashes remain in a private recovery archive outside this repository. These
exclusions do not turn previous measurements into new public qualification.

Retained public benchmark packages carry their source licenses and attribution:
the SemEval package preserves its CC BY 3.0 release notice, and the document
trial preserves the upstream Re-DocRED README and MIT license. Keep those notices
with the data. The [generalization fixture](generalization/README.md) carries
Wikipedia attribution and the excerpt/adaptation license. Synthetic regression
fixtures and generic authoring templates remain available. Customer research is
not approved for this public checkout.

Customer-specific kits and affected derived evidence have been removed. See the
[removal record](../../docs/operations/repository-data-removal.md) for the scope,
withdrawn claims and retained-evidence limitations. New regression examples must
use synthetic organizations and keep customer research outside this repository.
