# Product logo in the console

- Date: 2026-09-10
- Status: Unreleased
- Kind: UI

Replace the sidebar's generic graph icon and sign-in shield with the supplied
CogniGraph mark. Bundle a UI copy of the product SVG, preserving its path and
cropping only its transparent outer margins. A shared CSS mask uses brighter
teal on the dark sidebar and the existing accent on the light sign-in screen.

The 32-pixel sidebar mark aligns with the wordmark and remains centered in the
72-pixel collapsed rail. The sign-in mark is 38 pixels. Product branding retains
an accessible name when the visual wordmark is hidden; the login mark is
decorative beside the visible heading. The sibling master SVG remains unchanged.

## Validation

Biome/TypeScript, all 72 existing Bun tests and production bundling passed.
The Rust release server served the bundled SVG with HTTP 200, correct MIME and
matching bytes. Browser verification covered sign-in, expanded/manual-collapsed
sidebars, refresh, and 1600/1280/1067/1181/1179-pixel viewports. No new browser
warnings or errors were recorded. The [logo audit](../../ui/audit/2026-09-10-logo/audit.md)
contains screenshots, source provenance and measured geometry.

No Rust behavior changed. No provider calls, resets of existing databases or
remote publication were performed for this branding change.
