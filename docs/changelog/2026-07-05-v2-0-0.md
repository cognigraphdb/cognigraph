## Record

The second major iteration of the platform, tagged as the first release:
what began as an Arango-backed Python port is now a native-first Rust
knowledge-graph platform — CGQL v2 (joins, subqueries, EXPLAIN ANALYZE,
pushdown), memory-primary redb persistence, Semantic Neurons governed
construction (Arc B: 7/8, blind eval pending), auth/RBAC, semantic query
cache, packaged ops (Docker, backup/restore, CLI, CI). 328 tests green.

- **BREAKING — env naming sweep (decision_env_naming.md):** every
  CogniGraph-owned knob is now `COGNIGRAPH_*` (`COGNIGRAPH_AUTH_ENABLED`,
  `COGNIGRAPH_JWT_SECRET`, `COGNIGRAPH_CGQL_*`, `COGNIGRAPH_LOG_FORMAT`,
  `COGNIGRAPH_EMBEDDING_*`, ...); the semantic query cache family is
  `COGNIGRAPH_QUERY_CACHE_*` (distinct from the paged document cache's
  `COGNIGRAPH_CACHE_BYTES`). Ecosystem-standard names (`OPENAI_API_KEY`,
  `ARANGO_*`, `RUST_LOG`) stay bare. Legacy names are NOT read; the
  server warns loudly at startup for any it finds set.
- OpenAPI drift test: mounted routes and openapi.yaml checked both ways
  in the test suite; the nest→module mapping self-verifies against
  main.rs (first run found zero drift).
- Persistent-mode load benchmark: reads unaffected by persistence;
  independent single-doc writes ceiling at ~255/s (serialized ~4 ms redb
  commits); `/batch` measured at ~13.8k docs/s (one transaction per
  batch). Server-side group commit recorded as a design trigger.
- Dependency hygiene: openssl 0.10.81 (clears all Dependabot alerts),
  full semver-compatible lockfile refresh, `cargo audit` clean (one
  informational: `paste` unmaintained via tokenizers; resolves with the
  deferred tokenizers 0.23 bump).
