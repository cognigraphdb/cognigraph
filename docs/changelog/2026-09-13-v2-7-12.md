- Date: 2026-09-13

## Changes

Raw provider traces, labelled research runs, UI captures and operational inventories
move to private evidence storage. Public engineering guides retain reviewed
conclusions, small test inputs and path/size/SHA-256 references. The
[public evidence batch](2026-09-13-public-evidence-and-hosted-qa.md) resolves
CG-75–CG-77 and adds the distribution check to shared CI. Enterprise source
licensing and the database runtime contract are unchanged.

[CG-78's archive navigation repair](2026-09-13-archive-navigation-validation.md)
extends link validation to historical reading copies while preserving exact
originals with hash-bound exceptions. [CG-79](../issues/CG-79.md) fixes the SPA
test helper's temporary-directory leak and removes 984 verified old fixtures.
The four existing route tests pass under an isolated TMPDIR with no leftovers.

The [QA and cleanup workflow](2026-09-13-explicit-hosted-qa-and-docker-cleanup.md)
requires explicit requests for Railway tests and removes owned local Docker
resources after checks. The first Docker Hub release's
[post-release record](2026-09-13-first-docker-release.md) is included; its immutable
images remain v2.7.11.

## Qualification and publication

Publish this source candidate through the protected develop PR and subsequent
main promotion, with full local CI and both Linux/amd64 Docker editions, followed
by GitHub's required CI. The shared gates include strict Clippy and Rust tests in
both editions, UI/browser and Native HTTP acceptance, archive links, distribution
policy, advisories, and packaged persistence and Helm backup checks. The private
originals are additionally verified against the public catalog before publication.

Detailed local and remote delivery receipts belong in private package
`runs/2026-09-13-v2.7.12-release/`. No provider calls, research holdouts, hosted QA,
Docker Hub publication or Git-history rewriting are part of this source release.
The current-tree split does not erase material from earlier Git commits.
