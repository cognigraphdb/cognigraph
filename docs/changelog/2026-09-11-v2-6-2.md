# 2.6.2 — Repository data removal

- Date: 2026-09-11
- Status: v2.6.2
- Kind: Maintenance

## Changes

Remove customer-specific research, sales assets and derived records from the
code repository history. Retain generic grounding tests with synthetic names,
withdraw affected aggregate evidence, and retire regeneration of removed inputs.
See the [scope and publication boundary](../operations/repository-data-removal.md).
The uncommitted Community/Enterprise packaging work is a separate change.

## Validation

The publication gate requires the current CI suite and Docker build, an exact
ref manifest, a clean all-history removal receipt and an immediate incoming-PR
check. Offline fixture validation and release-binary recount cover retained
construction behavior. No LLM calls or holdout execution are required.
