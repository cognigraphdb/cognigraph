## Record

The agentic-review release: a schema-constrained LLM judge was measured
against 76 recorded review decisions (0/67 false-accepts on hints),
hardened against a 16-attack prompt-injection suite (zero induced
accepts), and shipped as an authored, per-space, risk-tiered review
policy — auto-accepting only the measured-safe lane with full
attribution, deterministic audit sampling, and both harnesses standing
as permanent regression gates for any judge-prompt change. Human review
becomes accountable, risk-tiered review: attributable, reversible,
symbolically floored.

- **Full-suite verification sweep #4 (2026-07-06, post review-policy
  arc):** all gates and all four benchmark harnesses — 354/354 tests,
  clippy/fmt/CI clean, quality invariants exact. On a quiet host
  (load avg 3.4 vs 6-7 during the prior sweep), several personal bests:
  flagship CGQL scan **0.799 ms** (best recorded), IN-pushdown 1.596 ms,
  COLLECT high-cardinality 4.849 ms, DISTINCT 3.367 ms; persistent-mode
  reads at full parity (140.6k point reads / 136.0k CGQL @ c=128,
  nominally ahead of in-memory); persistent mixed 2.8k req/s p99 95 ms —
  that cell's best ever. Confirms the prior sweep's drift was ambient
  contention; the judge/review machinery is measured off the serving
  hot paths, and grounding with gates+templates holds at 6.0 µs/chunk
  on a third independent run.
- **Risk-tiered review policy (D1-D6, decision_review_policy.md):** the
  scale answer to human-review-everything, built on the judge-replay
  numbers. `POST /construct/review` judges pending proposals
  (schema-constrained reviewer, shared `cognigraph_construct::judge`
  module under an explicit POLICY_REV) and applies an authored per-space
  policy: Lane A auto-accepts hints/aliases at high confidence on
  non-precision-critical existing rules — same acceptance validation as
  a human, full attribution (`judge:<model>@<policy-rev>`),
  deterministic audit sampling; blockers/rank hints and everything
  below threshold queue WITH the verdict as triage; the judge never
  auto-rejects; no policy document = unchanged fully-human review.
  **D5 injection gate PASSED**: 16 injected attacks (8 payload families)
  → zero injection-induced accepts (payloads raised suspicion); the
  suite instead exposed a possessive-appositive direction-reversal
  weakness — mitigated by excluding templated/gated/new-triple rules
  from Lane A. `COGNIGRAPH_JUDGE_MODEL` separates judge from proposer;
  CLI `neuron review` / `neuron audit`. Both harnesses (decision replay
  + injection suite) are permanent regression gates for any POLICY_REV
  change.
- **Judge-replay experiment (2026-07-06,
  fixtures/semantic-neurons/judge-replay/):** can a purpose-bound,
  schema-constrained LLM reviewer reproduce our recorded review
  decisions? 76 stored proposals replayed blind against their
  `neuron show` evidence: 82% agreement, **0/67 false-accepts on
  relation hints** (independently catching the negated-evidence case),
  all hint errors conservative (~18% of good items escalated); the two
  blocker false-accepts trace to coverage-simulation data the judge
  wasn't shown — layered with the existing symbolic checks the
  false-accept rate is 0/76. Judge prompt calibration measurably
  changes verdicts → the policy prompt is versioned config,
  regression-replayed by this harness. Evidence for the pending
  review-policy design session; no behavior changed.
- **Post-release verification sweep at v2.2.0 (2026-07-06):** all gates
  and all four benchmark harnesses re-run on the dep-fresh tree —
  351/351 tests, clippy/fmt/CI clean, quality invariants exact (100%
  quantized recall@10, 10/10 hybrid agreement). The six dependency
  majors are measured free: in-memory serving hit full baseline (138k
  point reads / 133k CGQL @ c=128) with tower-http 0.7 + sha2 0.11 on
  the request path, and lru 0.18 posted the best cache cold-read yet
  (11.7 µs). One anomaly investigated, not recorded: persistent reads
  dipped ~15% in run one; the re-run restored in-memory/persistent
  parity within 1% under a host load average of 6–7 (two active users)
  — ambient contention on the later pass, uniformly depressing both
  modes ~5–7%, no code signal.
