# 2.7.0 — Community builds and a fresh repository

- Date: 2026-09-11
- Status: v2.7.0
- Kind: Release

## Changes

Publish the sanitized current product as one root snapshot in the newly created
code repository. Earlier Git branches, tags and PR history are not carried over.
Dated engineering records remain available; their earlier commit references
belong to the former repository. The private archive and recovery copies are
outside this publication.

The owner approved public distribution after changing the fresh repository's
visibility. Exclude 25 restricted corporate/market research and judge-replay
files, preserving their original bytes in a private external archive. Synthetic
test organizations replace reused research names. Licensed public benchmark
packages retain their attribution; the Wikipedia-derived generalization fixture
now carries an explicit source/adaptation notice. The offline CG-24 recount
requires a separately authorized external fixture directory.

Include [CG-45](../issues/CG-45.md): Community is the default server, CLI and
Docker build, with Enterprise available through `--features enterprise` and the
documented packaging options. Helm's application version is 2.7.0. Read replicas
and manual standby are assigned to Community but remain unimplemented, as recorded
in the [licensing decision](../decisions/decision_licensing.md).

The [first-publication hook](../operations/push.md#initial-publication-to-a-fresh-repository)
binds the reviewed root commit to the new GitHub repository's identity. It
also requires the reviewed visibility to remain unchanged. It
requires an empty remote, a version increment, passing CI, Docker and UI gates,
and a final incoming-PR and remote-state check.

## Verification scope

The publication gate runs formatting, strict Clippy and all workspace tests in
both editions, Python workflow tests, dependency boundaries, documentation,
issue identity, both Docker builds and the frozen UI build checks. Live release
HTTP/CLI probes and both Helm/Docker backup checks cover CG-45 packaging.
Service-gated Arango and model tests remain distinct from executed live checks;
no provider calls or qualification holdout run is part of this release.
Local checks do not establish a remote CI result or a Kubernetes deployment.

Initial preparation passed on 2026-09-11: **42 Python workflow tests**, formatting,
strict Clippy in both editions, **776 Community and 967 Enterprise Rust test
entries**, the code documentation and issue checks, both Docker builds, and
the UI lint/type checks, tests and production build. Each Rust edition count
includes eight Arango entries that returned early without an exported password.

Both images passed 10 Helm rendering variants, 11 rejection cases and live
authenticated import/backup probes. The full edition probe used the exact
packaged release binaries in a disposable container and passed Community
CRUD/query/retrieval/Lua behavior, CLI gating, ordinary file/snapshot compatibility,
65 Enterprise-only specification paths, governed-state refusal and Enterprise
tenant isolation. All runtime data and embedding responses were synthetic.

The subsequent visibility guard passes **43 Python workflow tests**, including
refusal of a public/private change during verification. The final publication
gate repeats CI, both Docker builds and the UI checks against the reviewed
public snapshot after the fixture exclusions and synthetic test changes.
