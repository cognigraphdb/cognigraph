# CG-182: Community --help and the CLI guide omit shipped commands and flags

- Status: Open
- Priority: P3
- Area: CLI / docs
- Found: 2026-11-11
- Verification: Pending (source-confirmed in the 2026-11-11 review; not executed)

## Problem and evidence

The CLI parser is hand-written (`crates/cognigraph-cli/src/args.rs`), so the
usage texts are maintained separately.

- `index list|ensure|drop` ([CG-86](CG-86.md)) parses and executes in both
  editions, but is absent from `usage-community.txt` and from
  `docs/operations/cli.md`, which says "`cognigraph --help` lists everything".
- `--max-record-bytes`, `--max-expanded-bytes` and `--max-files` are accepted
  (`arangodump/options.rs:55-90`) and documented in
  `docs/reference/arangodump-import.md`, but appear in neither usage text nor
  the guide.
- The guide reduces exit codes to "1 on server errors, 2 on usage errors";
  local file, JSON and connection failures also exit 1.
- `read_password` echoes the typed password (`client.rs:100-116`), and
  `--token` is accepted on the command line.
- The guide's title is "# Cli".

## Acceptance

- [ ] Both usage texts list every command and flag the parser accepts in that edition, and a test asserts it for each command variant.
- [ ] `docs/operations/cli.md` matches, including exit codes.
- [ ] Password entry does not echo.
