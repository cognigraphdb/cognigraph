# CG-104: Lua scripts reach os, io and jit through the leftover module() global

- Status: Open
- Priority: P1
- Area: Lua / sandbox
- Found: 2026-11-11
- Verification: Pending (reproduced live on 2026-11-11, 2.7.39 Community release build)

## Problem and evidence

`crates/cognigraph-lua/src/runtime.rs` loads `StdLib::ALL_SAFE`, which includes
`io`, `os`, `package` and `jit`, and then hides them by setting their globals
to nil (lines 79-82 and 135-148). LuaJIT's package library also registers the
global `module`, which the sandbox leaves in place. `module(name)` looks the
library up in the registry's `_LOADED` table, where the hidden libraries still
live, and makes it the environment of the calling chunk.

Reproduced through `POST /api/lua/execute` with
`COGNIGRAPH_LUA_INSTRUCTION_LIMIT=100000`:

- `module("os"); return {rc = execute("true")}` returns `{"rc":0}`;
  `getenv` and `remove` are callable too.
- `module("io"); local f = popen("echo cg-sandbox-probe"); return f:read("*a")`
  returns `"cg-sandbox-probe\n"`.
- `module("jit"); on(); while true do end` never returns. The worker stayed at
  100% CPU after the client disconnected and after SIGTERM. The same loop
  without `jit` stops with "Script exceeded instruction limit".

Any role with the Lua execute scope, including the read-only script runner,
can run shell commands as the server user and read its environment and files.
This reopens [CG-1](CG-1.md) (JIT can be switched back on) and removes the
basis of the [CG-81](CG-81.md) disposition that no script reaches
`io`/`os`/`package`. The sandbox tests only assert that the named globals are
nil. Other limits of the Lua runtime are in [CG-129](CG-129.md).

## Acceptance

- [ ] `io`, `os`, `package` and `jit` are never loaded into the script state (preferred), or `module` and every other route to `_LOADED` is unreachable.
- [ ] Regression tests call `module("os")`, `module("io")`, `module("jit")` and `module("package")` and each fails; the live HTTP harness asserts the same.
- [ ] `docs/architecture/lua.md` and the CG-81 disposition note describe the sandbox as built.
