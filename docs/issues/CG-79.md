# CG-79: Remove leaked SPA test fixture directories

- Status: Resolved
- Priority: P2
- Area: Server tests / cleanup
- Found: 2026-09-13
- Verification: Four existing SPA route tests pass with an isolated TMPDIR and leave it empty; 984 verified historical fixtures removed.

## Problem and evidence

The server's SPA route tests created one temporary console distribution per
request and returned only its path. Nothing owned directory cleanup. Repeated
local checks left 984 directories containing the synthetic index and stylesheet.
The leak was confined to the test helper; production console serving is unchanged.

## Acceptance

- [x] Keep the fixture alive until the streamed response body is consumed.
- [x] Remove each fixture on normal completion and unwinding; surface normal cleanup failures.
- [x] Run the existing route tests with an isolated temporary root and verify no leftover files.
- [x] Remove only old fixtures whose names, contents and process ownership are verified.

## Resolution and verification — 2026-09-13

The [SPA helper](../../crates/cognigraph-server/src/spa.rs) now owns a
`tempfile::TempDir` through response-body consumption and explicitly closes it
before returning. The guard also cleans up if request handling panics. The
existing four route tests cover eight requests, including deep links, real assets,
unknown API routes and exact routes. All pass; the isolated temporary root is empty
after the test process exits.

All 984 old directories matched the synthetic fixture bytes, contained no symlinks
or unexpected files, and had no active creating PID. Only those reviewed files
and directories were removed. Other temporary captures and backups were preserved.
The inventory, cleanup receipt and focused test output are preserved privately in
`runs/2026-09-13-v2.7.12-release/`. The complete release gate additionally exercises
both editions, real local servers and packaged console delivery.
