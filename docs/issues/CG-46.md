# CG-46: Helm backups need isolated selectors and safe snapshot handling

- Status: Resolved
- Priority: P2
- Area: Deployment / backups
- Found: 2026-09-10
- Verification: Rendered chart and live Docker/HTTP backup, plus failure-path tests

## Problem and evidence

The proposed chart's Services and StatefulSet matched the name/instance labels
also assigned to backup pods. Its shell client interpolated the admin password
into JSON without escaping and accepted any export beginning with an opening
brace or bracket, allowing malformed responses to be marked complete before
retention deleted older files.

## Resolution

Server selectors now require the server component label; backup pods have the
backup component. Custom labels cannot override chart identity. A packaged
Python standard-library client safely encodes login, downloads to a temporary
file, parses the complete JSON and checks the snapshot envelope before renaming
it and applying retention. Positive integer retention and single-writer replica
values are enforced; authenticated query instructions include a token.

## Verification

- `python3 scripts/check-helm.py --live`: eight valid chart variants and seven
  invalid-value cases pass. Server/backup selector separation is asserted.
- The rendered server and backup run as UID/GID 10001 with a read-only root,
  dropped capabilities and disposable writable data. Real HTTP health, login,
  synthetic document import and backup passed with a password containing quotes,
  a backslash, newline and Unicode. The stored document appears in the snapshot.
- `scripts/tests/test_helm_backup.py` exercises malformed/truncated exports,
  HTTP 500, special-character login and retention preservation over real local
  HTTP. Old snapshots survive export failure; unrelated files are retained.
- No Kubernetes cluster deployment, PVC scheduling, ingress/operator integration
  or restore drill was performed. Decoded snapshot validation requires enough
  job memory; the chart guide documents this limit.

## Acceptance

- [x] Server selectors exclude backup pods.
- [x] Valid passwords survive JSON encoding and a real server login.
- [x] Failed exports cannot prune completed backups.
- [x] Render guards and the packaged client have reproducible validation.
