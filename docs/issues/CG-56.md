# CG-56: Console results remain attached to changed inputs and failed graph requests

- Status: Open
- Priority: P2
- Area: UI / results
- Found: 2026-09-11
- Verification: Source review and browser input-change/network-outage reproduction

## Problem and evidence

Query, Lua and search hold result state independently of their edited inputs.
For example [QueryScreen.tsx](../../ui/src/screens/QueryScreen.tsx), lines 24–26
and 60–83, renders the previous result with the current editor and bind variables,
without a submitted-input snapshot or stale marker. The same pattern exists in
LuaScreen and SearchPanel. Out-of-order executions are additionally possible
through CG-55.

Live: execute a query returning four document keys, then replace the editor with
`RETURN "not executed"` without running. The same Result panel and timing remain
beside that new text. [Capture](../../ui/audit/2026-09-11-full-review/04-stale-query-result.png).

Graph has a stronger error case. `loadTraversal` retains `graph` after a failure;
the JSON branch renders `graph.raw` without the error shown by the visual branch
([GraphScreen.tsx](../../ui/src/screens/GraphScreen.tsx), lines 80–84 and 213–233).
After a successful Alpha traversal, the audit stopped its forwarding proxy,
entered Gamma and ran again. The old Alpha JSON remained after “Failed to fetch”
toast expiry, with no persistent error in the workspace.
[State](../../ui/audit/2026-09-11-full-review/graph-failed-request.json),
[capture](../../ui/audit/2026-09-11-full-review/06-graph-failed-json.png).

[Full UI review and environment](../../ui/audit/2026-09-11-full-review/audit.md). No application fix was made in this audit.

## Acceptance

- [ ] Associate each result with immutable submitted inputs and show when current inputs differ, or clear results deliberately.
- [ ] Show loading/failure state in both graph views; retained previous results must be visibly identified as previous results.
- [ ] Ignore obsolete responses and test changed query/bind/vector/graph/script inputs, failed reruns and reversed completion order.
