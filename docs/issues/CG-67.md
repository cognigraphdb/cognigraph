# CG-67: Remove the ArangoDB runtime backend and reject retired configuration

- Status: Resolved
- Priority: P2
- Area: Storage / runtime
- Found: 2026-09-12
- Verification: Both Rust editions, 514 Native release-binary checks, cross-edition CLI/snapshot/tenant probes and nine browser regressions; [report](native-runtime-2026-09-12.md)

## Problem and evidence

At 2.7.1 (`efe9839`), [the server manifest](../../crates/cognigraph-server/Cargo.toml)
depends unconditionally on `cognigraph-arango`, and
[startup](../../crates/cognigraph-server/src/main.rs) selects it through
`COGNIGRAPH_BACKEND=arango`. Its unknown-backend branch falls back to Native.
Simply removing the Arango match arm could therefore turn a retired setting
into an apparently successful empty Native deployment.

The owner approved [Native-only storage](../decisions/decision_native_only.md).
The owner clarified that there are no existing users or live deployments, so
the cleanup may freely break earlier development configuration. Preserve useful
Native capability and public CGQL/authorization contracts, without maintaining
Arango-specific compatibility behavior.

## Scope and dependencies

Depends only on [CG-65](CG-65.md); blocks [CG-68](CG-68.md).
CG-64/CG-66 are deferred and must not delay this work.
Remove the adapter crate, workspace/dependency edges and startup/configuration
surface. Review server search/query, Lua, construct/server test dependencies,
query-language enum branches and edition/verification scripts. Remove obsolete
AQL-specific behavior where it has no retained contract owner; keep useful
`GraphBackend` capabilities and test doubles.

Do not move support into Enterprise or an optional feature. The existing AQL
comparison can remain external migration education; there is no importer to
preserve or implement here. Historical reports remain separate from current
runtime guidance.
Never edit local `.env` files, existing stores or source dumps during cleanup.

## Acceptance

- [x] The adapter directory, workspace member and runtime/dev dependency edges are removed; default and Enterprise dependency trees contain no `cognigraph-arango` and no replacement Arango runtime driver.
- [x] Native startup works directly. Delete the advertised backend selector or restrict any retained selector to Native with generic validation before writes; eliminate the invalid-value fallback. No Arango-specific shim, migration diagnostic or legacy-setting compatibility is required.
- [x] Arango URL/database/user/password and vector-mode configuration and help/examples are removed. No advertised configuration or API path selects Arango.
- [x] Public HTTP/Lua queries retain parsed CGQL, mutation/read authorization and budgets. Tenant/cache wrappers and supported Native modes retain their contracts without Arango-name conditionals substituting for capabilities.
- [x] Both editions pass fresh Native startup and CRUD/query/traversal/search/auth/restart probes, plus rejection probes for any retained selector. Verification needs no importer or Arango service.
- [x] Pass required Rust checks, edition/modularity checks where applicable, shared UI/browser gates for affected surfaces, and documentation/issue validation. Update owning guides with the implemented state and link final qualification in CG-68.

## Verification and resolution

Resolved on 2026-09-12. Both editions now open Native directly. The selector and
adapter-specific settings were deleted, so selector rejection probes are not
applicable. Lua embedding no longer offers an opaque query permission. Hybrid
search and promotion history use typed backend operations. The original title
is retained as a stable issue identity; clarified acceptance permits removal
without a legacy error surface.

The [runtime report](native-runtime-2026-09-12.md) and
[manifest](evidence/native-runtime-2026-09-12/manifest.json) bind source, fixtures,
binaries and captures to `bcec5b0` plus this change. Required Rust checks passed
in both editions (722/913 reported passing tests), together with 514 HTTP/Lua
checks, cross-edition CLI/snapshot/tenant probes, 161 UI tests and nine Chromium
journeys. Helm rendering, script, edition, modularity and documentation checks
passed. Provider skips and evidence boundaries are recorded separately.

[CG-68](CG-68.md) still owns final Docker/Helm live qualification and broader
active-document reconciliation before first deployment. This change is not a
new release, push, image publication or deployment. Normal versioning and the
incoming-work/full-validation gates apply before an authorized push.
