# CG-94: Split propose.rs and directed.rs in cognigraph-construct to the module line budget

- Status: Open
- Priority: P3
- Area: Construct / modularity
- Found: 2026-09-22
- Verification: Pending
- Scheduling: Owner request 2026-09-22 after CG-90; pure refactor, no behavior change

## Problem and evidence

The workspace targets 300–400 lines per module. Two `cognigraph-construct`
modules touched by [CG-90](CG-90.md) are well over it, and the size predates
that change:

| File | Lines | Shape |
|---|---|---|
| `crates/cognigraph-construct/src/propose.rs` | 872 | Report types (lines 14–75), the neuron proposal path (`neuron_schema`, `candidate_chunks`, `propose_neurons*`, `propose_one`, lines 77–265 and 605–714), the blocker proposal path (`propose_blockers_report`, `propose_blockers_covering`, `propose_one_blocker`, `blocker_schema`, lines 266–604), and helpers (`kebab`). |
| `crates/cognigraph-construct/src/directed.rs` | 509 | Contract types and `DIRECTED_POLICY` (lines 46–90), quote and endpoint matching (`find_loose`, `find_endpoint`, lines 93–180), the pure gate `gate_directed_proposals` (181–328), taxonomy validation, prompt and schema (329–411), and `directed_ingest` (412–end). Inline tests already moved to `directed_tests.rs`. |

Both files mix a public contract with two or three internally separable
concerns. The split is mechanical: no function changes body, only its module
path and visibility. The line budget is a recommendation (owner, 2026-09-22):
cohesion decides where to cut, not the count.

Related but out of scope here, for a later ticket if wanted:
`draft.rs` (1,197 lines), `grounding.rs` (1,190), `materialization.rs`
(662), `preparation.rs` (629) and `advisor.rs` (617) in the same crate.

## Proposed split

- `propose.rs` keeps the report types and the public `propose_*` entry
  points; `propose/neurons.rs` takes `neuron_schema`, `candidate_chunks`,
  `propose_one` and `kebab`; `propose/blockers.rs` takes the blocker path
  including `blocker_schema` and `propose_one_blocker`. Target: each file
  under 400 lines.
- `directed.rs` keeps the contract types, `DIRECTED_POLICY` and
  `directed_ingest`; `directed/gates.rs` takes `gate_directed_proposals`
  with `find_loose` and `find_endpoint`; `directed/prompt.rs` takes
  `DIRECTED_SYSTEM`, `proposal_schema` and `validate_taxonomy`. Public
  re-exports keep `cognigraph_construct::directed::{gate_directed_proposals,
  DirectedProposal, DIRECTED_POLICY}` stable for
  `tests/directed_contracts.rs`, `tests/directed_refusals.rs` and the
  server routes.
- Tests stay in their separate files; any module that gains tests gets a
  sibling `_tests.rs` via `#[path]`.
