# CG-71: Package and qualify the first Community deployment with the console

- Status: Open
- Priority: P1
- Area: Delivery / deployment
- Found: 2026-09-12
- Verification: Packaging and deployment qualification in progress; no live database acceptance yet

## Problem and evidence

The owner selected one Community instance on Railway with the React console,
and deferred Docker Hub publication. The existing image contains only the
API/CLI. Railway mounts volumes as root, while the image runs as UID 10001;
build-time ownership does not initialize that mounted storage. No database has
been deployed yet. The separate website is already live.

## Implementation

The image builds frozen Bun console assets and serves them from Rust at `/ui`.
Its default user remains unprivileged. A bounded entrypoint accepts root only
for the fixed Railway mount contract, provisions `/data/native` privately, and
executes the server as UID/GID 10001 with no new privileges. Existing ownership
is checked rather than recursively repaired; symlinks are rejected.

[Railway operations](../operations/railway.md) owns service configuration,
credentials, backups and the verification sequence. Source deployment uses the
verified main candidate; no image registry publication is required.
