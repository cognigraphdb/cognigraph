- Status: Open
- Priority: P3
- Area: Docs / status and navigation
- Found: 2026-11-11
- Verification: Pending (source-confirmed in the 2026-11-11 review)

## Problem and evidence

**Issue registry.** `docs/issues/README.md` says "Current registry: 79
Resolved, 1 Closed without change, and 3 Open issues" and "CG-64 and CG-66
remain Open". Its table, before this review, had 96 Resolved, 1 Closed
without change and 5 Open, with CG-64, CG-66 and CG-81 Resolved. Every file
has a row and every status matches; only the prose is stale. CG-84 to CG-87
are Resolved but still carry "Scheduling: Deferred optional backlog".

**Implementation plan.** `docs/implementation-plan.md` is headed "reviewed
2026-09-14" while its body cites v2.7.33. It says source changes remain
uncommitted (`:49-51`), CG-81 tracks unfixed findings (`:56-59`), CG-64 and
CG-66 are deferred (`:127-129`, `:157-158`), 7 issues are Open (`:140-141`)
and ARM manifests are not part of the checkpoint (`:311-314`). Other lines of
the same file say the opposite (`:17-22`, `:135-138`, `:174-177`,
`:306-308`).

**Entry points.** `docs/README.md:17-18`, the repository instructions
(`AGENTS.md:63-64`) and `docs/decisions/README.md:45`, `:87` call the importer
"optional and deferred" while the index lists its decisions as Active.

**Backend wording.** `docs/examples/lua-scripting.md` has a "Backend
Detection" section and says the examples "work on all backends";
`docs/architecture/components.md:115` says every database backend implements
the trait; `AGENTS.md:252` describes the backend-contract skill as checking
"across backend implementations" (the skill itself is current). The source
trees in `components.md` omit current route and provider files and show four
files as directories.

**Skills.** The validation commands in `.claude/skills/*/SKILL.md` lack
`--locked` and the Enterprise pass that the repository instructions require,
and the release skill covers crates.io but not the Docker publishing run.

## Acceptance

- [ ] The "Current registry" sentence is removed or generated from the table, and checkpoint sentences are clearly dated history.
- [ ] The plan's header and counts are current or point to the registry; no current document calls CG-64 or CG-66 deferred.
- [ ] The Lua examples, the components guide, the repository instructions and the skills describe Native storage modes and the current gates.
