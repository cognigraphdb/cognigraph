# CG-21: Concurrent neuron acceptance can commit a forbidden hint/blocker pair

## Problem

Acceptance loads the other accepted neurons, validates the combined set, then updates one neuron in a separate operation. Two concurrent requests accepting a hint and blocker for the same triple can both validate against the old set and both commit. The resulting accepted state violates the explicit conflict rule.

Automated review similarly captures proposed/accepted state before awaiting the completion provider, then writes acceptance without checking the current status. A concurrent human rejection or retirement can therefore be overwritten by the stale review result.

## Evidence

`crates/cognigraph-server/src/routes/neurons.rs:162-212`; `crates/cognigraph-construct/src/validate.rs:75-107`; `docs/decisions/decision_relation_blocker.md`.

`crates/cognigraph-server/src/routes/construct.rs:1216-1299,1394-1418` — automated review snapshots state before the provider await and later updates the neuron without a conditional transition.

## Reproduction / comparison

Start with both conflicting neurons proposed. Interleave both acceptance requests after `load_accepted` but before their individual updates. Each sees no accepted conflicting peer; both succeed.

## Acceptance criteria

Serialize validation and transition per tenant/space or use a conditional atomic state update. Route automated acceptance through the same boundary and require the expected source status/revision to still match. Add deterministic tests for conflicting concurrent acceptances and human rejection/retirement racing automated review; prove stale transitions cannot overwrite the newer decision.

Verify the affected runtime or documentation contract before closure. Rust changes require all repository gates. See [review evidence](review-2026-09-08.md).

## Resolution

Human transitions and both auto-accept lanes now share a tenant/incarnation
critical section from the current reads through validation and publication.
Provider calls remain outside it. Automated publication requires the exact
captured proposed document, policy, and ontology to remain current; stale
results are reported in `skipped` without overwriting human or review metadata.
Current symbolic conflicts queue, while failed accepted-set reads and malformed
rows stop acceptance. Snapshot import shares the transition boundary.

Nine deterministic regressions cover conflicting accepts, rejection/retirement
races, both judge lanes, duplicate reviews, source edits, read failures, and
tenant/incarnation isolation. The final release passed 99 HTTP scenarios and
162 exact document comparisons after restart in all three persistent Native
configurations. Formatting, strict Clippy, and all 937 reported Rust tests passed. The
corrected fixture/accounting attempts
are recorded in the [verification report](neuron-lifecycle-2026-09-09.md).
Dedicated judge endpoint configuration was subsequently resolved separately
as [CG-36](CG-36.md), with its own controlled release routing checks.
