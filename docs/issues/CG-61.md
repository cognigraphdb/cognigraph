# CG-61: React Router lockfile retains an advisory-affected release

- Status: Resolved
- Priority: P2
- Area: UI / dependencies
- Found: 2026-09-11
- Verification: Patched dependency, clean Bun audit and live Rust-served routing checks

## Problem and evidence

`bun audit` exits 1 with one high-severity advisory for the directly installed
`react-router@8.2.0` ([lockfile](../../ui/bun.lock), line 424).
[GHSA-qwww-vcr4-c8h2](https://github.com/advisories/GHSA-qwww-vcr4-c8h2)
affects the 8.x range below 8.3.0 and identifies 8.3.0 as patched.
[Audit evidence](../evidence/ui-2026-09-11-full-review.md#artifact-4a4672814e8d1035b1b7).

The advisory explicitly limits this CSRF issue to unstable React Server
Components APIs. CogniGraph uses client-side `createRoot` and `BrowserRouter`
([main.tsx](../../ui/src/main.tsx)), Bun static bundling and a Rust API. No RSC
action integration was found. This records dependency remediation and a failing
audit, **not a demonstrated exploitable CSRF vulnerability in this console**.
The normal UI check/test/build suite still passes and does not run this audit.

[Full UI review and environment](../evidence/ui-2026-09-11-full-review.md#artifact-2a08bd45b55e9bd0cb9c). No application fix was made in this audit.

## Acceptance

- [x] Review and update React Router to a compatible patched stable release and refresh the lockfile deliberately.
- [x] Pass Bun check/test/build and a fresh dependency audit, with an explicit reviewed disposition for any remaining findings.
- [x] Retest direct routes, login redirects, navigation, history and production Rust-served assets after the update.

## Resolution — 2026-09-11

Update the direct requirement and lockfile to React Router 8.3.1, the current
stable release reviewed against the [upstream changelog](https://reactrouter.com/changelog#v831).
Only React Router changes in the resolved dependency graph. Existing React and
React DOM 19.2.7 satisfy its peer requirements; no application source changes
were needed. Frozen installation preserves the updated lockfile.

`bun audit` changes from exit 1 with one high advisory to exit 0 with no findings
across 213 checked packages. No remaining findings require an exception.
Biome/TypeScript, 161 tests (783 assertions) and the production build pass.

The real Enterprise Native server on an isolated origin passes direct-document
login, invalid-login recovery, encoded-key lookup, keyboard navigation, browser
Back/Forward, user-route refresh, Admin/HostAdmin root landings and denied-route
handling. Eight direct HTML routes and the JavaScript/CSS responses match the
production files. API checks separately confirm the role boundary.

[Audit, captures, HTTP results and sealed manifest](../evidence/ui-2026-09-11-router-update.md#artifact-f2ee775cf86eb46ca1d7).
The advisory remains limited to the upstream RSC surface; this is dependency
remediation, not a newly demonstrated console exploit. No Rust changes, remote
CI run or publication. Automated browser/CI coverage remains [CG-60](CG-60.md).
