# CG-44: Closing a Collections dialog loses keyboard focus

- Status: Resolved
- Priority: P2
- Area: UI / Collections accessibility
- Found: 2026-09-10

## Live reproduction

Focus Create document and press Enter. Focus moves to the modal's Close button.
Press Escape: the modal disappears but focus moves to the document body, losing
the keyboard user's position. Conditional unmounting bypasses the modal's usual
close-animation restoration; retaining conditional mounting is required by the
existing Bun/Ant Design compatibility constraint.

## Acceptance

- [x] Keyboard dismissal and Cancel restore focus to the surviving opener.
- [x] The modal remains conditionally mounted and keyboard-operable.
- [x] A removed opener after confirmed deletion is not focused.

## Resolution and verification

Resolved in the 2.6.1 candidate. The [Collections audit](../evidence/ui-2026-09-10-collections.md#artifact-088100ac46441b68bcc4)
records the implementation, live before/after observations, checks and explicit
coverage limits. No existing database or frozen experiment evidence was changed.
