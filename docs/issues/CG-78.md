- Status: Resolved
- Priority: P2
- Area: Documentation / CI

## Problem and evidence

The docs checker excluded every archived plan except the archive index. Six
broken references survived the initial rebase: five fixture directories and a
CI YAML path. A scan restricted to Markdown and JSON targets missed them.
The shared CI/push workflow already runs the docs checker; its archive exclusion,
rather than an absent link-checking gate, caused the coverage gap.

The two plans had also been edited while their index still described exact
editorial snapshots. Their committed bytes matched the original migration
hashes; navigation amendments required explicit reading-copy provenance and
preservation of those original bytes.

## Acceptance

- [x] Repair all six targets and check archived navigation regardless of target extension, including directories and Markdown anchors.
- [x] Preserve both original plans with verified hashes, label amended reading copies and retain the historical migration manifest unchanged.
- [x] Limit link exemptions to explicitly named, hash-verified originals; reject changed/missing originals, invalid policies and implicit exemptions by filename.
- [x] Add regression coverage through the existing shared CI gate, verify optional product-checkout behavior, and remove the ignored legacy bytecode remnant.
