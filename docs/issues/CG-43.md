# CG-43: Collections controls overflow at scaled desktop widths

- Status: Resolved
- Priority: P2
- Area: UI / Collections layout
- Found: 2026-09-10

## Live evidence

At 1067 × 667 CSS pixels, the collection filters end at x=660.875 while Reset
ends at x=725.531, under the inspector. The long-key inspector edit header extends
to x=1115.062 and its actions to x=1087.062, beyond the 1067-pixel viewport.
At 1280 pixels the same header extends past the viewport to x=1290.921.

## Acceptance

- [x] Inspector keys and edit controls fit at 1600, 1280 and 1067 CSS pixels.
- [x] Collection filters and Reset remain visible and operable.
- [x] Table and inspector retain their internal scrolling and reachable actions.
- [x] Check both sides of the 1180-pixel sidebar breakpoint and document resize
      emulation separately from native OS scaling.

See the [dated audit](../evidence/README.md) for screenshots and
the final geometry measurements.

## Resolution and verification

Resolved in the 2.6.1 candidate. The [Collections audit](../evidence/ui-2026-09-10-collections.md#artifact-088100ac46441b68bcc4)
records the implementation, live before/after observations, checks and explicit
coverage limits. No existing database or frozen experiment evidence was changed.
