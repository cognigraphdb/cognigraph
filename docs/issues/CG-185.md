# CG-185: Tracked ui/.npmrc hard-codes a developer-machine path, and .gitattributes names a vendor directory that no longer exists

- Status: Open
- Priority: P3
- Area: Repository hygiene; public boundary
- Found: 2026-11-11
- Verification: Pending (source-confirmed in the 2026-11-11 review)

## Problem and evidence

- `ui/.npmrc` is tracked and sets `cache=` to an absolute path under a
  personal home directory, at a location that is not this checkout. The public
  repository therefore shows a local username and directory layout, and any
  npm-compatible tool that honours `cache` writes to, or fails on, a foreign
  path. `scripts/check-public-distribution.py` has no rule for absolute home
  paths.
- `.gitattributes` marks `vendor/tantivy-0.26.1/**` as vendored, but the
  directory is `vendor/tantivy-0.26.2`. The 375 vendored files count as
  first-party in language statistics and review tools.

## Acceptance

- [ ] `ui/.npmrc` carries no machine-specific path, and the distribution check rejects absolute home-directory paths in tracked configuration.
- [ ] `.gitattributes` matches the vendored directory, ideally as `vendor/**`.
- [ ] The owner decides whether the path needs removing from history under the data-removal procedure.
