# CG-80: Published container base packages carry fixable vulnerabilities

- Status: Resolved
- Priority: P1
- Area: Container security and CI
- Found: 2026-09-14
- Verification: Full local CI, both Docker/Helm suites, baseline rejection and patched-image scans passed on 2026-09-14; publication pending

## Problem and evidence

Docker Hub's published Community v2.7.14 digest
`sha256:9539d08db8a5441cd99ee1871c1b3f03c22305eb890a0d908cb4095fb77a6335`
reports 68 CVEs on 2026-09-14: 5 critical, 10 high, 6 medium, 44 low and 3
unspecified. Its fixable filter lists 26 CVEs, including all five critical and
nine of the ten high findings. Critical/high findings originate in the base layer.

The runtime `apt-get update && apt-get install ...` refreshed indexes but did
not upgrade unrelated packages already installed in Debian. Both editions use
that runtime construction. A real pull and independent Trivy scan reproduced
28 fixable binary-package/CVE pairs, representing the same 26 unique CVEs.
This is package/advisory evidence, not an exploit reproduction.

## Resolution

- Upgrade installed runtime packages before adding dependencies, preserving
  Debian stable, UID 10001, the entrypoint, curl healthcheck and console contract.
- Rebuild the named runtime stage without cache on every shared Docker build.
- Scan both immutable local image IDs before runtime qualification. Any
  available fix at any severity blocks CI. Keep unfixed findings in full reports.
- Reject unavailable scans, missing OS inventory, wrong-image reports and local
  suppression/configuration overrides; upload reports even when CI fails.

The [security decision](../decisions/decision_container_vulnerability_gate.md)
owns the gate. [CG-81](CG-81.md) owns remaining unfixed findings, which this
patch does not claim to resolve. The [verification report](../verification/container-security-2026-09-14.md)
records fixed versions and executed checks. Source changes and rebuilt images
are local; replacing Docker Hub `latest` requires a separately versioned release.

## Acceptance

- [x] All 26 fixable CVEs from the original Hub report are absent from scans of
  both rebuilt Linux/amd64 editions; no fixable findings remain.
- [x] Both editions retain authentication, CLI/API, console, persistence,
  volume hardening and live Helm backup behavior.
- [x] Regression tests prove scanner failure, invalid coverage, wrong subjects
  and fixable findings cannot produce a successful gate.
- [x] Complete final shared CI and documentation verification.
