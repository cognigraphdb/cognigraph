## Problem and evidence

The crate-level doc comment in `crates/cognigraph-construct/src/lib.rs`
described the neuron lifecycle as `proposed → accepted → graduated` and pointed
to `docs/semantic-neurons-port-design.md`, which does not exist.

`NeuronStatus` in `crates/cognigraph-construct/src/types.rs` is
`proposed | accepted | rejected | retired`. Graduation is a leave-one-out
redundancy report (`crates/cognigraph-construct/src/report.rs`,
`GET /api/neurons/graduation`), and retirement is a separate human transition
(`POST /api/neurons/{key}/retire`). The design note lives at
`docs/architecture/design-notes/semantic-neurons-port.md`.

The same wording appears in the Semantic Neurons paper's property list
("reversible and staged"), where §6.1 already discloses that graduation is an
instrument rather than a state. The crate comment was the only place in the
source that presented it as a status.

## Resolution

Working-tree change on 2026-09-22: the comment now reads
`proposed → accepted | rejected, and later retired; graduation is a
leave-one-out redundancy report, not a status`, and the design-note path is
corrected. `cargo fmt --all -- --check` passes and
`cargo doc -p cognigraph-construct --no-deps --locked` builds; the two
pre-existing rustdoc intra-doc-link warnings in `draft.rs` and
`webnlg/mining.rs` are unrelated and unchanged.
