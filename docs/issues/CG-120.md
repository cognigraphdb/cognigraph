# CG-120: Native derivatives are created for collections that do not exist and are never removed on drop

- Status: Open
- Priority: P2
- Area: Native / derivative lifecycle
- Found: 2026-11-11
- Verification: Pending (source-confirmed in the 2026-11-11 review; not executed)

## Problem and evidence

Three gaps in the lifecycle of rebuildable derivatives:

- **Created for unknown collections.** Sidecar vector search does no existence
  check before building (`crates/cognigraph-native/src/memory/vector.rs:24-98`).
  For any name it writes and fsyncs a `<db>.<sha>.vectors` file, maps it and
  caches the mapping. Paged mode then answers `200 []` where the other modes
  answer `CollectionNotFound` (`:111-141`). Hybrid search probes a possibly
  missing `side_views` collection by design, so it rebuilds an empty sidecar
  after every write.
- **Kept after drop.** `drop_collection` (`memory/backend.rs:266-279`) clears
  only the triple index, the document cache and one map entry. The `.vectors`
  file and the `.tantivy` directories stay on disk, and the quantized vectors,
  adjacency and text indexes stay in memory until restart. Tokenized text and
  int8 embeddings of a dropped collection therefore survive in the data
  directory and in any copy of it. Only tenant retirement cleans up.
- **Unbounded text-index cache.** The cache is keyed by collection plus the
  ordered field list (`memory/search.rs:177-233`, `memory/paged.rs:91-121`).
  Each distinct `fields` list sent to `/api/search/text`, including names that
  do not exist, builds and permanently keeps another index: a directory,
  mappings and a file-watcher thread.

[CG-99](CG-99.md) covers the rebuild race in the same code.

## Acceptance

- [ ] Unknown collections return `CollectionNotFound` in every storage mode and create nothing on disk.
- [ ] `drop_collection` removes the collection's derivative files and in-memory entries under the write lock.
- [ ] The text-index cache is bounded and superseded directories are deleted; tests assert no `.vectors` or `.tantivy` entry remains after a drop, in resident and paged modes.
