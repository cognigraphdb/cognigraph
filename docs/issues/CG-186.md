# CG-186: Documentation link gate skips six tracked Markdown files and every path cited in backticks or Rust comments

- Status: Open
- Priority: P3
- Area: Docs / validation; navigation
- Found: 2026-11-11
- Verification: Pending (source-confirmed in the 2026-11-11 review)

## Problem and evidence

`scripts/check-docs.py:98-113` scans the root `README.md`, `CHANGELOG.md`,
`AGENTS.md` and files under `docs/`, `crates/`, `ui/` and the skill
directories. It does not scan `LICENSING.md`, `CONTRIBUTING.md`, `CLA.md`,
`deploy/helm/cognigraph/README.md`, `clients/typescript/README.md` or
`vendor/README.md`. Their links were checked by hand and none is broken
today. The script also deliberately skips backtick paths (`:38-39`) and does
not read Rust comments.

References that point nowhere today:

- `docs/examples/api-usage.md:440-441` cites `docs/cgql-v1.md`; the file is
  `docs/reference/cgql.md`. `crates/cognigraph-query/README.md` uses the old
  name as link text.
- `README.md:83` links "React console" to the Evidence catalog instead of the
  console section of `docs/operations/running.md`.
- `docs/reference/cgql.md:102`, `:147` and
  `docs/architecture/native-storage.md:148` cite `benchmarks.md`; the file is
  `docs/research/benchmarks/native-backend.md`.
- Rust comments cite `docs/native-storage-model.md`,
  `docs/redb-primary-design.md` and `docs/vector-sidecar-design.md`
  (`crates/cognigraph-native/src/storage.rs:4`, `memory/mod.rs:34-47`, `:311`,
  `crates/cognigraph-server/src/config.rs:32-34`), `docs/benchmarks.md`
  (`crates/cognigraph-construct/src/grounding/negation.rs:24`),
  `docs/dailymed-pilot.md` (two construct examples) and
  `roadmap-2026-h2.md`, now under `docs/plans/archive/`
  (`answers.rs:1`, `propose.rs:120`, `propose/blockers.rs:6`).

## Acceptance

- [ ] Every tracked first-party Markdown file outside the vendored tree is link-checked, with a test for a file outside the current prefixes.
- [ ] Each reference above points at an existing file.
- [ ] Optionally, the check resolves backtick `docs/…md` paths in Markdown and in Rust comments.
