# CG-69: Automate Native CI and enforce verified repository changes

- Status: Open
- Priority: P1
- Area: CI and delivery
- Found: 2026-09-12
- Verification: Local CI and Docker passed; website PR CI passed; code PR qualification pending

## Problem and evidence

The workflow only accepted manual dispatch. GitHub listed no CI runs, main had
neither branch protection nor rulesets, and secret scanning/push protection were
disabled. Local verification omitted the CG-68 Native readiness harness, Helm
rendering/live backup checks, advisory scans and actionlint. Rust test/Clippy
commands could modify dependency resolution. The separate website had no workflow.

## Implementation

Automatic PR/main verification uses the same expanded CI and Docker runners as
local pre-push. The Native wrapper builds locked release binaries for both
editions and retains logs/failure summaries. Helm rendering and packaged backups
run in both editions. A required aggregate check rejects failed, skipped and
cancelled prerequisites. Full-SHA Actions and read-only credentials preserve
manual-main-only image publication. Dependabot proposes dependency updates.

The website has its own shared local/CI runner: workflow lint, frozen Bun
installation, audit, type/lint/tests and a disposable hardened Docker smoke
across all twelve SSR pages. Its private-repository plan currently does not
allow branch rulesets; no visibility/billing changes are authorized.

The first scan found h2 0.4.15 affected by RUSTSEC-2026-0258 and yanked
chacha20 0.10.1. The candidate updates them to 0.4.19 and 0.10.2 respectively.
Transitive informational advisories remain visible under [CG-70](CG-70.md).

## Qualification checkpoints

The script regression suite passes 70 tests, including injected Native build
and runtime failures, incomplete reports and execution of the actual aggregate
check with failed/cancelled/skipped prerequisites. These tests supplement the
real-binary acceptance gate; they do not replace it.

The expanded local `ci` suite passed on the versioned 2.7.2 working candidate:
strict locked Clippy in both editions; 722 Community and 913 Enterprise Rust
tests; 161 UI unit tests; all nine real-server browser cases; and the script,
formatting, docs, issue, edition, workflow and advisory gates. Each Rust run
reports two ignored provider tests; CI also disables the two live LLM loop
cases. These counts do not imply hosted-provider execution or holdout coverage.

Fresh release binaries passed 257 Native checks per edition across all four
storage modes, plus five Community and seven Enterprise startup rejections.
The wrapper retained its reports and binary hashes in the unique ignored
capture directory. Helm rendering passed ten variants and eleven rejection
cases per edition. The final committed candidate is rechecked by the installed
pre-push hook; the PR's check run owns remote qualification at its exact SHA.

The local Docker suite also passed for both Linux/AMD64 editions: image and
binary identity, packaged CLI/server, authentication, persistence/restart and
the rendered Helm backup in hardened containers. This working-tree run used
base commit `4fdaa47` in its image labels. The pre-push run rebuilds metadata
and verifies the final commit before branch publication; neither run uploads
an image. Deployment remains on hold.

GitHub API readback confirms active main ruleset `23050859`, the required
`CI required` check bound to GitHub Actions, full-SHA Action enforcement,
read-only workflow defaults, disabled workflow PR approvals, secret scanning,
push protection, Dependabot alerts and automated security updates. The private
website has the available Actions/Dependabot settings but no branch ruleset.

[Website PR #1](https://github.com/cognigraphdb/website/pull/1), version 1.1.4 at
`940fd1fdb6ceb6339748a1635d51c0a349fbb0af`, passed both its full local runner and
[GitHub CI](https://github.com/cognigraphdb/website/actions/runs/34696030170).
Each ran 37 tests / 1,109 assertions and the twelve-page hardened-container
smoke. Local Docker was ARM64; GitHub executed AMD64. The PR remains open.
