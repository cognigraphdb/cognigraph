# CG-103: Air-gapped embeddings through a sidecar: separate endpoint settings, Granite R2 measurement, side views and Semantic Neurons validation

- Status: Open
- Priority: P2
- Area: Embeddings / deployment
- Found: 2026-09-24
- Verification: Pending
- Scheduling: Owner request 2026-09-24: sidecar embeddings for air-gapped deployments (forensics, pharma), Granite R2 first; a local LLM follows separately

## Problem and evidence

Air-gapped deployments (forensics, pharma) cannot call hosted embedding
APIs. The [CG-98 benchmark](../research/benchmarks/embedding-recall-2026-09-23.md)
measured only hosted models and two Ollama models, and the owner has removed
Ollama. The owner chose a sidecar over embedding inside the binary.

Source review found two gaps for a sidecar:

- `crates/cognigraph-server/src/main.rs` builds the `openai` embedding
  provider from `OPENAI_API_KEY` and `OPENAI_BASE_URL`, the same settings
  as the completion lane. An embedding sidecar therefore cannot run next to
  an OpenAI-hosted model, or a local model on another port, and it must be
  given a key it never checks.
- `crates/cognigraph-embeddings/src/openai.rs` always sends an
  `Authorization: Bearer` header, even with an empty key.

The `onnx` feature of `cognigraph-embeddings` has an in-process ONNX
provider, but the server does not wire it in. It is out of scope here.

## Owner decisions (2026-09-24)

- Separate embedding endpoint settings: `COGNIGRAPH_EMBEDDING_BASE_URL`
  and an optional `COGNIGRAPH_EMBEDDING_API_KEY`.
- Hugging Face Text Embeddings Inference (TEI) is the standard sidecar.
- Measure both IBM Granite Embedding Multilingual R2 sizes (311M and 97M)
  on the frozen CG-98 inputs.
- Validate side views and Semantic Neurons with the sidecar embedder, using
  the current API completion model on a small corpus. A local LLM follows
  later.

## Acceptance

- [ ] Embeddings can use their own OpenAI-compatible endpoint with or
      without a key. The completion key is never sent to it, and invalid
      settings fail at startup.
- [ ] Both Granite R2 sizes are measured through TEI with the CG-98 harness,
      with results against the CG-98 embedders.
- [ ] Side views (generation, storage, hybrid retrieval) and Semantic
      Neurons (ingest, evaluate, side-view proposals, review, re-ingest) work
      end to end with the sidecar embedder.
- [ ] An operations guide shows an offline TEI deployment. The decision
      record and configuration reference describe the settings.
