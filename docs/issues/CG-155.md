# CG-155: Multi-architecture image publication is recorded as done but has not happened

- Status: Open
- Priority: P2
- Area: Release / Docker publishing; docs
- Found: 2026-11-11
- Verification: Pending (from repository records on 2026-11-11; Docker Hub was not queried)
- Scheduling: Needs an owner-authorized promotion to main and Docker Hub publish; before the 2026-12-10 token expiry.

## Problem and evidence

[CG-87](CG-87.md) is Resolved with "[x] The release publishes a
multi-architecture image manifest" ticked, while its own verification line
says the first multi-architecture publication is pending the next authorized
push and release. The repository records agree that it is still pending:

- `origin/main` is at v2.7.14 and publication happens only from `main`; the
  workspace is at 2.7.39.
- `docs/operations/docker-hub/` holds one release receipt, for 2.7.11.
- `docs/operations/docker-publishing.md:61-63`, `docs/decisions/README.md:92`
  and `decision_multi_architecture_images.md` say the first multi-architecture
  publication is pending; `docs/implementation-plan.md:58-59` says Docker Hub
  still serves v2.7.14.
- `README.md:31-53`, `docs/operations/running.md:62-63` and
  `docs/operations/docker-hub/community.md` tell users to pull `:latest` and
  describe releases after 2.7.27 as amd64 and arm64.

A user on Apple Silicon who follows the quick start gets an amd64-only image
about 25 versions behind the documentation, without unique indexes, the dump
importer or LIMIT bind variables. The product-root instructions still say the
image is amd64-only "until CG-87 lands".

The publisher token is documented to expire on 2026-12-10
(`docker-publishing.md:53-54`).

## Acceptance

- [ ] The first multi-architecture publication is done and recorded with a receipt showing both platforms in the version and `latest` indexes.
- [ ] The README, running guide, publishing guide, decision index and the product-root instructions state the actually published version and platforms.
- [ ] The publisher token is rotated before 2026-12-10.
