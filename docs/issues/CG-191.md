## Problem and evidence

The workspace rules say earlier prototypes must not be described or cited,
and the repository instructions require synthetic organizations in tests.

**Prototype citations**

- `docs/architecture/design-notes/semantic-neurons-port.md` names the earlier
  research repository and its documents (`:4`) and describes a port of a
  named script (`:123`); the design-notes index lists it as a "Rust port".
- Comments in `crates/cognigraph-construct/src/grounding.rs:1-3`, `:39`,
  `lib.rs:1-4`, `validate.rs:2-3`, `types.rs:1-2`, `:176`, `eval.rs:5` and
  `tests/parity.rs:1` cite prototype source files or describe code as ported.
- Dated records: `docs/changelog/2026-07-05-v2-0-0.md:12` and
  `docs/issues/review-2026-09-08.md:71`.

**Names to confirm**

- `crates/cognigraph-construct/tests/directed.rs:48-100` and
  `src/directed_tests.rs:5-7` use a party name that appears to come from a
  public contract corpus rather than a synthetic organization.
- Fixture file names under `fixtures/semantic-neurons/generalization/` refer
  to a publicly reported 2024 incident involving a real company. It is not a
  client, but it is not synthetic either.

A targeted search for known client identifiers found none in the repository.
That search was not exhaustive.
