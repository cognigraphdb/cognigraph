## Resolution

Candidate v2.7.15 passes the full shared CI and Docker suites. Argon2 0.6 uses
OS-generated salts and preserves existing PHC passwords. The checksummed Tantivy
0.26.2 release retains the bounded lru fix because upstream still requires the
affected series. redb 4.2 reopens previous-version stores in all three persistent
configurations; authentication, stored JSON, text search and new writes survive
restart and the tested process-crash recovery.

Both Rust editions pass strict Clippy and tests; Native release acceptance, UI
unit/build checks and all 17 browser cases pass. Optional ONNX tokenization and
explicit local MiniLM inference pass. Both image scans report zero fixable
findings; unfixed image findings remain under [CG-81](CG-81.md), and the optional
paste maintenance warning remains visible under its existing review decision.

The [verification record](../verification/dependency-refresh-2026-09-14.md)
contains counts, limitations and the private evidence reference. Test servers,
stores and owned Docker test images were removed. No Railway test was run.
The combined CG-80/CG-82/CG-83 source remains uncommitted and unpublished;
public Docker images remain v2.7.14 until a separately authorized release.
