# CG-65: Preserve Native conformance coverage before retiring ArangoDB

- Status: Open
- Priority: P2
- Area: Storage / verification
- Found: 2026-09-12
- Verification: Pending

## Problem and evidence

Deleting the adapter without a test disposition could remove useful storage
and capability-boundary coverage. At 2.7.1 (`efe9839`),
[Arango integration tests](../../crates/cognigraph-arango/tests/integration.rs)
call the [shared contract](../../crates/cognigraph-core/src/contract.rs), while
server/construct tests instantiate Arango to exercise unsupported capabilities.
The [CGQL corpus](../../crates/cognigraph-query/tests/corpus/README.md) already
has 126 expected-result execution cases; it is not a live AQL oracle.

Native already runs contracts against memory, persistent and paged modes in
[native tests](../../crates/cognigraph-native/tests/). Preserve that coverage and
identify genuine gaps before [runtime retirement](CG-67.md). This is planned
verification work, not a claim that every Native path lacks tests.

## Scope and dependencies

First task in the revised [batch](../plans/native-only-2026-09-12.md); blocks
CG-67. CG-64/CG-66 are deferred and unrelated to this gate. Keep `GraphBackend`,
explicit capabilities, routed/cache wrappers and useful failure doubles. A
storage-mode comparison shares CGQL implementation and must not be described
as an independent query-language implementation.

Review adapter-dependent tests to identify useful Native regressions and failure
doubles; adapter-only tests can be deleted with the adapter. Keep this inventory
bounded to retained behavior, rather than preserving every historical test.
The owner authorizes breaking cleanup before first deployment. No live Arango
qualification, new AQL golden capture or compatibility guarantee is required.

## Acceptance

- [ ] Record a concise coverage disposition for the Native behavior retained and test doubles replaced; identify adapter-only test groups removed without recreating them.
- [ ] Preserve shared document/edge/traversal/vector/scan contracts across the supported Native modes, including persistent reopen and sidecar behavior.
- [ ] Keep independently expected CGQL results and targeted mutation, error, budget, cancellation and authorization regressions; fixed result arrays do not replace these behaviors.
- [ ] Replace tests that need an unsupported/failing backend with focused doubles without weakening their assertions or relying on an Arango connection.
- [ ] Preserve existing CGQL goldens and sealed evidence; routine Native checks no longer rely on Arango test setup or credentials.
- [ ] Pass focused conformance, full required Rust checks and real Native HTTP/Lua/persistence probes for changed behavior. Report executed coverage separately from any intentionally gated service cases.

## Verification and resolution

the direction; it does not establish replacement test coverage.
