## Problem and evidence

Environment-specific hostnames, platform identifiers and screenshots appear in
public operational evidence. The owner clarified that this instance is disposable hosted QA, not a permanent
operator console or public demo. Other applications run their own CogniGraph
instances. The final [lifecycle decision](../decisions/decision_hosted_qa_lifecycle.md)
replaces the initial permanent-ingress proposal. Public runbooks should describe
deployment using example values; actual inventories and original captures belong
in private evidence.

Read-only inspection confirmed application authentication is enabled, while
the optional application rate limit is unset and defaults to disabled. The
existing limiter keys by the TCP peer address, so enabling it behind a reverse
proxy alone is not a qualified per-client abuse control. No production flooding,
credential attack or unauthorized access was performed as part of this review.

A stopped QA service should stay stopped until a deliberate test session. The
source deployment trigger was removed; otherwise a later main push would restart
it. Application authentication remains configured and the existing volume remains
attached. No database reset, volume deletion, model call or holdout run occurred.
