# CG-168: Degradation report treats every templated rule as a dead pathway

- Status: Open
- Priority: P3
- Area: Construct / reports
- Found: 2026-11-11
- Verification: Pending (source-confirmed in the 2026-11-11 review; not executed)

## Problem and evidence

`fires` in `crates/cognigraph-construct/src/report.rs:243-281` calls
`affirms_phrase(&chunk.text, phrase)` with the authored phrase. A trigger that
contains `{source}` or `{target}` never occurs literally, so a rule whose
triggers are all templates is always reported as a degraded pathway. A plain
trigger that fires only in sentences the gate refuses is reported healthy.
Tests and examples use plain triggers only.

An ontology with templated rules therefore produces a report that lists each
of them as lost capability and prompts needless re-proposal.

## Acceptance

- [ ] Degradation is computed through `ground_chunk`, or with the same expansion and gate logic.
- [ ] A test covers a templated rule and a gated rule.
