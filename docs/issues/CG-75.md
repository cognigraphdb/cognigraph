## Problem and evidence

The published v2.7.11 tree contains 897 Semantic Neurons fixture files
(63,521,082 bytes), 171 issue-evidence files (4,414,051 bytes) and 815 UI audit
files (25,737,536 bytes). Raw provider requests include complete prompt bodies;
research packages include labelled corpora, outputs and repeated captures.
Most of these bytes are unnecessary for an ordinary developer checkout.

The owner selected a separate private evidence repository. Keep original bytes,
licenses, manifests and historical measurements there. Publish clear research
summaries, limitations and path/hash references; private artifacts are not
independently reproducible from the public checkout alone. A hash identifies
bytes; it does not prove the correctness of a measurement or constitute a signature.

Several files under the affected directories are runtime test inputs, acceptance
scripts or CI policy. Preserve the public verification contract by relocating
those inputs or supplying small equivalent fixtures before removing captures.
Public Rust source already contains construction prompts; this ticket narrows
capture distribution without claiming prompt secrecy while that source remains public.

See the [engineering batch](../plans/public-evidence-boundary-2026-09-13.md).
