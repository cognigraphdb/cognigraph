# CG-26: Governance and server modules substantially exceed the modularity convention

- Status: Resolved
- Priority: P2
- Area: Maintainability / reviewability
- Found: 2026-09-08
- Reviewed revision: `bc4bff1` (workspace 2.6.0; current drafts where noted)
- Resolved: 2026-09-09 (local checkpoint `8b8cceb`)
- Verification: Code-motion comparison, exact Rust gates, release HTTP/restart checks, Arango boundary, size guard

## Problem

The standing convention targets 300-400 lines, allows a soft 450-line limit, and requires splits in the feature arc. Several critical modules now span thousands of lines, combining wire contracts, validation, transitions, recovery, and tests. This makes boundary review difficult and is unresolved implementation debt explicitly acknowledged in the decision.

## Evidence

`docs/decisions/decision_file_modularity.md:18-28,61-66`; `crates/cognigraph-server/src/promotions.rs`, `jobs.rs`, `materialized_repairs.rs`, `artifact_consumption.rs`, `governance.rs`, and `routes/construct.rs`.

## Reproduction / comparison

At review time the largest files were promotions (15,014 lines), jobs (6,844), materialized repairs (4,599), artifact consumption (4,117), governance (3,996), and construct routes (2,833), including inline tests.

## Acceptance criteria

Create bounded refactor units along contract/validation/transition/recovery/test seams, preserving public behavior. Keep behavior fixes separate from mechanical moves. Run all standard gates plus existing live lifecycle checks after each relevant split; document any justified exceptions.

Verify the affected runtime or documentation contract before closure. Rust changes require all repository gates. See [review evidence](review-2026-09-08.md).


## Resolution

The six named files now expose compatible `mod.rs` entry points, with contracts,
validation, lifecycle operations, storage/recovery, and themed tests separated.
The 240 resulting files include 233 within the soft cap and seven explicitly
budgeted exceptions for coherent execution methods/scenarios. Other oversized
workspace files are outside these six refactor units.

All 1,087 declarations/methods matched the baseline after mechanical
normalization. Formatting, strict Clippy, all 961 reported workspace tests,
release build, and the new CI size check passed. Saved/final releases produced
identical signed authority and graph results across three Native modes and
restarts. Existing API and neuron lifecycle harnesses passed 57 and 99 checks;
a disposable Arango instance preserved the unsupported-M26 boundary and state.
See the [source map and verification report](server-modularity-2026-09-09.md)
for exceptions, corrected verification attempts, and coverage limits.
