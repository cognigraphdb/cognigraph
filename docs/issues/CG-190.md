# CG-190: LICENSING.md lists Community capabilities the shipped server does not have

- Status: Open
- Priority: P3
- Area: Docs / licensing and feature claims
- Found: 2026-11-11
- Verification: Pending (source-confirmed in the 2026-11-11 review)

## Problem and evidence

- `LICENSING.md:35` lists "index-assisted planning". No index-assisted
  planning exists in the query or Native crates;
  `docs/implementation-plan.md:85` and `docs/decisions/README.md:93` list
  secondary-index pushdown as later work, and `docs/reference/cgql.md:599`
  says planning does not optimise indexes.
- `LICENSING.md:38` lists embedding providers as "OpenAI-compatible, Ollama,
  Cloudflare, ONNX". The server accepts only `openai`, `ollama`, `gemini` and
  `none` (`crates/cognigraph-server/src/main.rs:238-283`). Cloudflare, OAuth
  and ONNX exist only as library modules ([CG-183](CG-183.md)), and Gemini,
  which is selectable, is not listed.

Other provider lists disagree with each other as well:
`crates/cognigraph-embeddings/src/lib.rs:3`,
`docs/architecture/components.md:205` ("OpenAI / Ollama") and the comment at
`crates/cognigraph-server/src/config.rs:11`.

The public positioning rule is no unmeasured or unimplemented claims.

## Acceptance

- [ ] `LICENSING.md` lists only capabilities reachable from the shipped binaries, or labels library-only ones.
- [ ] "Index-assisted planning" is removed or replaced with what exists (filter, projection and limit pushdown; unique constraints).
- [ ] There is one provider list, and the other places link to it.
