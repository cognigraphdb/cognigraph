dependency refresh was [CG-92](CG-92.md) on 2026-09-22.

## Resolution

Owner decisions of 2026-11-11 are in the
[refresh decision](../decisions/decision_dependency_refresh_2026_11_11.md).

- A full `cargo update` moved 130 crates. Every crate in the advisory table
  is on a fixed release.
- The three breaking upgrades were made: `lru` 0.19.0, `serde-saphyr` 2.1.1
  and Tantivy 0.27.0. None needed a source change.
- Tantivy 0.27.0 requires `lru ^0.18.2` itself, so the vendored snapshot was
  retired: `vendor/tantivy-0.26.2/`, its provenance record, the Cargo patch
  declaration and workspace exclusion, the Docker copy, the separately
  packaged licence file, `scripts/check-vendored.py` and its tests.
- `unicode-normalization` 0.1.26 moves to Unicode 18.0.0 and failed the M23
  compile-time guard. It is pinned at `=0.1.25` with an exception that expires
  on 2027-02-11; [CG-194](CG-194.md) tracks the migration.
- `ort` 2.0.0-rc.15 changed how sessions are created, and the optional ONNX
  provider no longer compiled. `onnx.rs` is adapted. No CI gate caught this
  ([CG-183](CG-183.md)).
- The console and the TypeScript client were refreshed with
  `bun update --latest`. Biome 2.6 formats Markdown by default; both projects
  exclude `*.md`.

Renovate's schedule was not changed. Whether it can keep up is an owner
decision and moved to [CG-195](CG-195.md).

## Verification

On v2.7.43 with rustc 1.99.1:

- `verify.py --suite dependencies`: 0 Cargo and 0 npm identities differ from
  a fresh resolution; 60 direct dependencies are current or covered by the
  one exception.
- `verify.py --suite advisories`: `cargo audit --deny unsound` reports only
  the pre-existing allowed `paste` maintenance warning; `bun audit` reports no
  vulnerabilities for the console (221 packages) and the client (36).
- `verify.py --suite ci`: passes. It includes both Clippy gates, 809
  Community and 1,036 Enterprise tests (2 ignored in each), 178 script tests,
  161 console tests, Helm rendering for both editions, Native acceptance (340
  checks per edition), the TypeScript client (32 unit and 8 live tests) and
  the browser suite (8 Community and 9 Enterprise tests).
- `scripts/check-dependency-upgrade.py`: stores written by the previous
  binary (Tantivy 0.26.2, redb 4.3) were reopened by the candidate in
  resident-embedded, resident-sidecar and paged-sidecar modes, for Community
  (previous 2.7.39) and Enterprise (previous 2.7.42). Logins, stored JSON and
  text search over the old data worked, then writes, a restart, an abrupt
  kill and a reopen.
- The optional ONNX feature passes Clippy and its offline tests, including
  the tokenizer regression. Its inference test needs a local model and was
  not run.

- `verify.py --suite docker`, run on commit `1cc17a4`: both edition images
  build on the pulled distroless runtime; the vulnerability gate finds no
  fixable finding (51 unfixed package findings per image remain in its
  report: 34 medium, 12 low, 5 unknown); the image checks, hardened container
  start-up and live Helm checks pass for both editions. A first attempt
  failed when the disk filled during the vulnerability scan; the rerun after
  clearing the build cache passed. The test images were removed afterwards.

Not run: model providers, research holdouts, Railway, any publication.
