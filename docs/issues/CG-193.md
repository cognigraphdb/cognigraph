# CG-193: Keep only tickets and the registry in the public issue directory

- Status: Resolved
- Priority: P2
- Area: Docs / public boundary
- Found: 2026-11-11
- Verification: `issue.py check`, `check-docs.py`, `check-decision-index.py` and `check-public-distribution.py` pass with the private folder present (links verified) and with it absent (248 and 6 links skipped); three new script tests pass
- Resolved: 2026-11-11

## Problem and evidence

`docs/issues/` tracked the `CG-N.md` tickets and their registry together with
38 dated records: two review reports and 36 remediation and verification
write-ups from September 2026, about 35,000 words. They are working
narratives rather than ledger entries, and the owner does not want them
published alongside the tickets. About 250 links in 137 public documents
point at them, including changelog records and archived plans that are kept
as written.

## Resolution

Owner decision of 2026-11-11, recorded in the
[private issue records decision](../decisions/decision_issue_records_private.md).

- The 38 records moved, byte for byte, to `docs/private/issues/`, which
  `.gitignore` now excludes.
- `python3 scripts/issue.py check` fails when `docs/issues/` holds anything
  but tickets and the registry.
- `scripts/check-docs.py` and `scripts/check-decision-index.py` treat a link
  to `docs/issues/<name>-YYYY-MM-DD.md` as a private record: verified against
  the private folder when present, skipped and counted otherwise. Other
  missing targets still fail.
- The evidence policy, the repository instructions and the registry
  conventions state where evidence is written from now on.

Not done here: the records already published stay in the public Git history,
and the private folder is unversioned. Both are noted in the decision.

## Acceptance

- [x] The tracked contents of `docs/issues/` are the tickets and the registry, enforced by `issue.py check` with a test.
- [x] The documentation gates pass in a checkout with and without the private folder, with tests for both and for a wrong anchor or unknown record.
- [x] The policy for new evidence is recorded in a decision, the evidence policy and the repository instructions.
